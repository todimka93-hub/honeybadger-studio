# ASYA Shorts Studio

Бесплатный монтаж YouTube Shorts из **отдельных** изображений, без коллажей.

## Что работает
- Каждый кадр — отдельный файл `assets/scene_01.jpg`, `scene_02.jpg` и т.д.
- Вертикальное видео 1080×1920, 30 FPS, плавное движение камеры с привязкой к главному объекту.
- Озвучка из `assets/voice.mp3`, длительность видео определяется аудио.
- Запуск с телефона: GitHub → Actions → Build Shorts → Run workflow.
- Готовый MP4 скачивается из **Artifacts** после успешного запуска.

## Подготовка
1. Добавьте фотографии по одной в папку `assets/` (JPG/PNG). Нужны именно отдельные исходные файлы.
2. Добавьте `assets/voice.mp3`.
3. При необходимости отредактируйте `scenes.json`: `focus_x` и `focus_y` — координаты объекта от 0 до 1, `motion`: `push`, `pull`, `pan_left`, `pan_right`, `static`.
4. Запустите workflow вручную. Он найдёт файлы `scene_*.jpg/png` по номеру. Настройки для недостающих номеров берутся по умолчанию.

Важно: этот проект **не обещает бесплатную ИИ-генерацию новых изображений**. GitHub Actions на обычных runner'ах без GPU занимается монтажом уже полученных кадров. Бесплатные внешние генераторы с гарантированными 10 изображениями пока не подключены.

Проект предназначен для публичного репозитория, где стандартные GitHub-hosted runners обычно бесплатны в рамках правил GitHub. Не загружайте личные/секретные материалы в публичный репозиторий.
